# Automation Tools

A collection of functional PowerShell automation tools, scripts, and administrative utilities developed for systems management, endpoint administration, software deployment, configuration, auditing, remediation, and workflow efficiency.

## Repository Structure

* **`Powershell/Administration/`** — User and endpoint administration utilities.
* **`Powershell/Audit/`** — System auditing and inventory tools.
* **`Powershell/Configuration/`** — Endpoint configuration and system-policy automation.
* **`Powershell/Deployment/`** — Application and software deployment automation.
* **`Powershell/Log_Ingestion/`** — Automation for collecting and processing operational log data.
* **`Powershell/Remediation/`** — Automated remediation for common endpoint issues.

## Examples

The repository includes automation for:

* Software and application deployment
* Microsoft 365 user administration
* Installed software auditing
* Endpoint configuration
* Windows power-management settings
* Autodesk configuration
* User-profile backup
* Log ingestion workflows
* Microsoft Edge and Outlook remediation
* System restart-history auditing

## Purpose

* Maintain version control for personal and production-focused automation tools.
* Develop and document practical PowerShell skills through real operational problems.
* Build reusable automation for repetitive systems-administration tasks.
* Document technical growth across systems administration, scripting, and cloud operations.
* Provide a clean, accessible portfolio of functional automation code.
